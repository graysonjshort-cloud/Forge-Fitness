# Forge Fitness v14.84.0 — Forge Intelligence Core

Introduces a normalized programming-decision ledger. Session autoregulation, exercise swaps, and Plan Editor moves now record what changed, evidence, confidence, scope, and duration. A unified Intelligence Core endpoint combines mesocycle, readiness, muscle development, progression state, active session and the decision log. Coach 4.0 consumes recent decisions and must distinguish session-only changes from persistent programming changes.
