# Forge Fitness v14.37.5.0

Clean static-scene rewrite.

This version intentionally removes animation from the calibration stage.

Goals:
- establish 1 Blender unit = 1 meter;
- measure the actual MPFB athlete before building equipment;
- scale the bench, rack and bar from athlete height;
- position the athlete on the bench using explicit MPFB landmarks;
- create one static lockout pose;
- verify athlete/bench/bar proportions before any motion is animated.

Only frame 1 matters in this build.

Once frame 1 looks correct, the next build will add bottom-position and rep animation.
