# Forge Fitness v14.26 — Comprehensive UI Polish

This build applies the full UI/UX polish pass across Forge.

## Home
The current workout is now the primary action. Home also shows readiness, today's remaining
nutrition, weekly completion, upcoming workouts, proactive coaching, and more useful empty states.

## Workout
The active workout now has visible session progress and a current-exercise card. Set logging
emphasizes previous performance, target reps, weight/reps entry, effort/RIR, and a large
Complete Set action.

The rest timer can stay active while the user views the workout. A floating timer remains
visible until rest ends or is skipped.

## Progress
Progress Intelligence is supplemented by workout consistency and weekly muscle-volume visuals,
while the existing strength and bodyweight charts remain intact.

## Nutrition
Nutrition is now a dashboard centered on calories remaining, macro progress, quick logging,
training fuel guidance, and meals grouped by Breakfast/Lunch/Dinner/Snacks/etc.

## AI Coach
AI responses can surface contextual action chips such as View Workout, Nutrition, Progress,
or Plan instead of presenting every answer as text only. Existing actionable Coach changes
remain intact.

## Plan
The weekly schedule is now a larger calendar-style layout that shows workout names, times,
duration, core/cardio add-ons, today, and recovery days.

## Equipment Log
Equipment artwork now has a fixed-width illustration column and a separate text column, which
prevents labels from touching or overlapping images regardless of illustration width.

## General polish
Supporting text is more readable, buttons provide subtle press feedback, empty states give the
user a next step, and Forge red is reserved more strongly for primary actions and active states.
