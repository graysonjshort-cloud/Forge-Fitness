# Forge Fitness v14.36.0–v14.36.2
v14.36.0 adds the exercise-ID-based form/demo metadata architecture and coverage API.
v14.36.1 adds Form Demo access during strength workouts and sequential Core, with reusable video/image playback and reduced-motion-aware autoplay.
v14.36.2 adds the full Form Guide: Demo, Setup, Common Mistakes, Breathing, and Control guidance, plus Exercise Directory integration.

Actual animation files are not fabricated in this build. The player is production-ready for original or commercially licensed assets once mapped to exercise IDs and reviewed.
