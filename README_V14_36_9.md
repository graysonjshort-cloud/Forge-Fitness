# Forge Fitness v14.36.9 — Articulated Demo V2

This is a quality-over-quantity release. No new exercise coverage was added.

The five reference demos were rebuilt with a more instructional articulated style:
- Back Squat
- Barbell Bench Press
- Romanian Deadlift
- Barbell Overhead Press
- Pull-Up

Improvements include defined torso geometry, visible joints, clearer equipment, exercise-specific motion,
red path/reference guides, and controlled multi-phase loops. The Bench Press now visibly changes elbow/wrist
geometry while the bar travels toward the chest rather than simply translating a stick figure.

All five are reset to Asset Ready and must be reviewed again under the existing six-gate review workflow.
The remaining 38 demos keep the v1 style until the v2 reference standard is approved.
