# Forge Fitness v14.36.10

The five reference form demos were rebuilt to a higher-fidelity vector standard after phone testing showed v14.36.9 was still too simple.

Updated: Back Squat, Barbell Bench Press, Romanian Deadlift, Barbell Overhead Press, Pull-Up.

Changes: filled torso/body geometry, thicker anatomical limb segments, more recognizable equipment, clearer joints and bar paths, more detailed movement-specific animation, larger 480×480 SVG canvases, and larger presentation in the app.

No new image files were generated. These are implemented directly as SVG/vector assets in the app. The remaining 38 demos are unchanged until this quality standard is approved.
