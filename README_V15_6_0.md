# Forge Fitness v15.6.0 — Notifications & Workout Reminders

Forge reminders are now opt-in and domain-specific. Users can independently control device notifications, workout reminders, missed/incomplete workout alerts, recovery and deload reminders, nutrition reminders, calendar conflicts, schedule-change alerts, and morning briefs. Device permission is requested only when the user enables device notifications. Notification delivery is deduplicated locally and uses the service worker when available.
