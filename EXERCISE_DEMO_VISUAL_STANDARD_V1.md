# Forge Motion Diagram Visual Standard v1

All v14.36.7 demo assets use the same original Forge visual language:

- 360 × 360 SVG viewBox.
- Dark Forge background.
- Silver/white athlete.
- Red equipment or movement-reference element.
- Minimal environment and no decorative gym scene.
- Approximately 2.6–3.0 second loops.
- Start → controlled working position → brief hold → controlled return.
- Exercise name remains readable under the motion figure.
- Assets are diagrams, not photorealistic anatomy.
- Asset-ready does not mean biomechanically reviewed.

Review still requires all six v14.36.6 gates before Forge labels a demo Reviewed.
