# Forge Fitness v14.36.6 — Demo Review Workflow

- Added persistent per-exercise review checklists.
- Six gates: correct exercise, setup/equipment, range of motion, joint alignment, loop quality, and phone testing.
- Demo Library now opens a review screen for asset-ready demos.
- Review notes can be saved.
- A demo automatically becomes `reviewed` only when all six gates pass.
- Removing any passed gate automatically returns it to `asset_ready`.
- The first five original SVG demos remain unreviewed by default; this release does not falsely certify their biomechanics.

The SVG approach remains lightweight and is supported by modern browser SVG animation capabilities.
