# Forge Fitness v14.35.3

Core and cardio are now intelligent, independent training modules with their own tracking.

## Smarter Core
- Core circuits remain separate from strength workouts.
- Lower-body strength days bias toward lower-fatigue core choices.
- Upper-body days can emphasize anti-rotation / anti-lateral-flexion work.
- Circuits cover lower abs/hip flexion, anti-extension, obliques, and trunk flexion.
- Each module explains why Forge selected it.

## Smarter Cardio
- Lower-body days favor steady-state cardio to reduce strength/recovery interference.
- Higher-intensity intervals are preferentially placed after upper-body work.
- Fat-loss plans receive more cardio duration; strength plans receive less.
- Each cardio module includes a selection reason.

## Independent Tracking
Core and cardio no longer inherit strength-workout completion.
- Core logs sets, reps, hold duration, load mode, and RPE.
- Cardio logs completed minutes, RPE, optional distance, and optional pace.
- Core/cardio module sessions have independent completion states.
- Progress includes completed core sessions, completed cardio sessions, cardio minutes, and best timed core holds.
