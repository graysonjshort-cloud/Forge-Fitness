# Forge Fitness v14.41.0 — Readiness + Live Workout Adjustment

Adds a 15-second readiness check-in using energy, soreness, motivation, sleep quality, and available time. Forge can shorten today’s workout, trim accessory volume on low-readiness days, or keep the original prescription. It also shows live guidance after unusually hard or easy sets. Session adjustments do not rebuild the underlying program.
