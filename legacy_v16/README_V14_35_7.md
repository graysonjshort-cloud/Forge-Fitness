# Forge Fitness v14.35.7

- Weekly Muscle Volume now expands to a full-width chart and shows every trained muscle group instead of only the top five.
- Core and Cardio progress are separate cards rather than one combined card.
- Core shows completed circuits and current scheduled count.
- Cardio shows completed sessions, total cardio minutes, and current scheduled count.
- Core and Cardio modules can be moved independently between strength-training days.
- Moving a module does not move the strength workout.
- A target day cannot already contain the same module type.
- Completed module sessions cannot be moved.
- Fresh PWA cache for installed app updates.
