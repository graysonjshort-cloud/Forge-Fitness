# Forge Fitness v14.50.0 — Unified Intelligence Milestone

Combined milestone release building on v14.44–v14.46.

## Calendar Intelligence 2.0
- New `/me/calendar/intelligence` endpoint combines the Forge workout schedule, Google Calendar availability when connected, and recovery spacing between training days.
- Calendar settings now surfaces conflicts, tight recovery gaps, and a weekly placement recommendation.

## Coach Actions 2.0 consolidation
- Coach retains explicit preview/approval before applying workout shortening, moves, swaps, skips/restores, exercise swaps, and nutrition actions.
- Calendar Fit is upgraded to Calendar Intelligence language so Coach considers both time availability and recovery spacing.

## Exercise Directory 2.0
- Adds 51 additional movements on top of the v14.46 directory expansion.
- Directory intelligence now exposes movement plane, programming roles, and recovery cost in addition to fatigue, stability, joint stress, skill, hypertrophy, strength, conditioning, tracking mode, bodyweight mode, and selection tags.
- Expanded seed target is 200 exercises before any additional legacy/base rows are merged.

## v14.50 integration goal
Recovery/deload intelligence, program-change approval, PR trends, readiness, substitutions, Calendar, Coach, and the exercise directory now share a more consistent decision vocabulary without removing existing behavior.
