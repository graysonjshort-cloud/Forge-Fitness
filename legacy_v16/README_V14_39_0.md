# Forge Fitness v14.39.0

UX and polish release built on the v14.38.x modularization series.

## Changes
- Mobile safe-area support for modern Android/iOS devices.
- Stronger keyboard focus states and 44px+ interactive field sizing.
- Primary navigation now exposes `aria-current=page`.
- Toasts are announced through an ARIA live region.
- Main content is programmatically focusable.
- Reduced-motion support respects OS accessibility preferences.
- Refined press feedback, disabled states, card/button depth, and small-screen spacing.
- PWA asset/cache version advanced to v14.39.0.

No training, nutrition, progression, database, or Coach behavior was intentionally changed.
