# Forge Fitness v14.36.5 — First Original Demo Pack

First five original Forge motion-diagram assets:
- Barbell Back Squat
- Barbell Bench Press
- Romanian Deadlift
- Overhead Press
- Pull-Up

These SVGs are lightweight, loop continuously, work with the existing offline cache, and contain no third-party media.

Important: assets are `asset_ready`, not `reviewed`. They remain visibly unreviewed until their exercise identity, setup, range of motion, joint alignment, loop quality, and mobile presentation are checked. This prevents Forge from presenting an unverified diagram as authoritative technique instruction.

`tools/import_exercise_demo_manifest.py` registers asset-ready entries against matching exercise names in the local database.
