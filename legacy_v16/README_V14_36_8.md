# Forge Fitness v14.36.8

## Demo library expansion
Added 28 more original Forge SVG motion diagrams, bringing the bundled total to 43 assets.

New coverage includes squat variations, dumbbell/machine pressing, shoulder pressing, assisted pull-ups,
rows, lateral raises, curls, triceps work, hip thrust/bridge, calf work, and more core movements.

## Faster review
- Added an Asset-Ready Review Queue.
- Previous / Next navigation stays inside the review screen.
- Saving a completed review automatically advances to the next asset-ready demo.
- The queue excludes already reviewed demos.
- Review status still requires all six v14.36.6 gates.

## Persistence
Bundled demo assets auto-register into existing persistent databases during startup, so Render users do not
need to recreate accounts or wipe data.

No new asset is automatically marked biomechanically reviewed.
