# Forge Fitness v7.1 — Equipment multi-select fix

Fixed the Equipment onboarding screen:

- Equipment tiles now support true multi-select.
- Tapping an already-selected equipment tile deselects it.
- Selecting an individual equipment item exits Full Gym mode.
- Full Gym now toggles on/off instead of forcing all tiles permanently.
- The Full Gym card now visibly shows selected/unselected state.

Example:
Dumbbells + Bench + Cable Machine can now all be selected at the same time.
