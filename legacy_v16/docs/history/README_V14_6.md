# Forge Fitness v14.6 — Expanded Exercise Directory

The bundled database now contains 142 exercises and 715 substitution links.

New Exercise Directory functionality:
- Search by exercise, muscle, movement, or equipment
- Filter by primary muscle
- Filter by difficulty
- Toggle "My Equipment" to hide incompatible exercises
- Open a detail page for sets, reps, rest time, movement pattern, muscles, equipment,
  progression method, beginner suitability, and notes
- Existing program generation and workout swapping use the expanded library
- New exercise substitutions are generated around movement pattern and target-muscle similarity
- Existing exercise records are preserved; the migration only inserts missing names

Open it from Plan > Overview > Browse Exercise Directory.
