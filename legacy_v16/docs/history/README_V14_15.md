# Forge Fitness v14.15 — 25+ Minute Cardio

Adds a fourth Cardio Intensity/duration option:

- Light — 10 min
- Moderate — 15 min
- High — 20 min
- Intense — 25+ min and favors longer steady-state aerobic work

Cardio Frequency remains separate and still controls how many workouts receive cardio add-ons.
Cardio exercises remain swappable.
