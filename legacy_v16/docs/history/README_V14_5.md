# Forge Fitness v14.5 — Expanded Equipment Log

The Equipment Log now contains 40+ items across Free Weights, Benches & Racks,
Cable & Machines, Attachments & Accessories, Bodyweight, and Cardio.

New functionality:
- Search equipment
- Filter by category
- Show only added equipment
- Edit equipment-specific details such as dumbbell max weight, cable stack limit,
  rack safeties, adjustable-bench features, treadmill incline, etc.
- Save optional notes
- Expanded presets
- Detailed equipment is passed to Forge Coach
- Specific machines map back to the current generator's broader equipment capabilities
  so the existing programming engine remains compatible.
