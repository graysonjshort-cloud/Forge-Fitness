# Forge Fitness v14.16 — Nutrition Tracking

Adds Nutrition as a sixth main tab.

Features:
- Daily calorie tracking
- Protein, carbohydrate, and fat tracking
- Editable daily calorie/macro targets
- Food/meal logging
- Meal categories: Breakfast, Lunch, Dinner, Snack, Pre-Workout, Post-Workout
- Date picker for reviewing previous/future days
- Daily remaining calories/macros
- Delete logged foods
- Persistent SQLite nutrition data

This is the first nutrition MVP. It intentionally uses manual food/macronutrient
entry so it does not depend on an external food database yet.
