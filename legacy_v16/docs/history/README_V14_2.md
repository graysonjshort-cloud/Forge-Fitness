# Forge Fitness v14.2 — Strength Progress

The old Overall Strength Index has been replaced with a mainstream-friendly metric:

    Strength Progress: +X.X% since you started

The permanent baseline is 0%. Changing between 30D, 90D, 1Y, and ALL only changes
which history points are displayed; it does not redefine the baseline.

Individual exercise views still show estimated strength (estimated 1RM) in pounds,
plus the percentage change since the user's first valid logged set for that exercise.
