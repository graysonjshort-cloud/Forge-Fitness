# Forge Fitness v14.35.6

Core circuits now progress from prior performance and include built-in rest.

- Each core set is logged immediately when completed.
- Completing a set starts a dedicated core rest timer.
- Normal transitions use ~30–35 seconds; round-style recovery uses ~60–75 seconds.
- Rest can be skipped.
- Circuit completion stays locked until every programmed set is logged.
- Recent core reps/hold duration and average effort feed into future generated targets.
- Comfortable timed holds generally progress by about 5 seconds.
- Comfortable rep sets increase the target range.
- Near-limit performance holds or slightly reduces the next target.
- Each core exercise displays a progression explanation.
- Estimated core duration includes rest.
- Fresh PWA cache for installed phone updates.
