# Forge Fitness v14.35.5

- Core circuits track every set independently.
- Each core set uses the same Easy / Moderate / Hard / Very Hard / Limit effort/RIR controls as strength exercises.
- Timed core exercises have an independent timer for every set.
- Cardio uses the same button-based effort system instead of a raw RPE number.
- Changing session length now changes programmed volume so 30-, 45-, and 60-minute plans do not keep the same prescription.
- Bodyweight resistance is classified separately from required equipment. Pull-ups, chin-ups, neutral-grip/scapular pull-ups, bench dips, hanging knee raises, and hanging leg raises default to Bodyweight while still requiring their bar/bench.
- Assisted pull-ups/dips and machine dips remain machine-loaded.
- Fresh PWA cache for installed phones.
