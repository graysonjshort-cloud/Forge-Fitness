# Forge Fitness v14.25.1 — Functional PR Lift-Type View

The Personal Records screen now has two working views.

**By Exercise** keeps the existing exercise-by-exercise records.

**By Lift Type** groups records using each exercise's real Forge movement pattern:
Squat Patterns, Hinge Patterns, Lunge & Single-Leg, Leg Isolation, Push Patterns,
Pull Patterns, Arms, Shoulder Isolation, Core, Loaded Carries, Conditioning, and Other.

The lift-type view also has Lower Body, Upper Body, Core, and Conditioning filters.
Groups expand/collapse, show the best record in the group, and every exercise row opens
the existing Exercise History page.

Bodyweight/no-load exercises fall back to a best-reps display when a weighted estimated
1RM is not meaningful.
