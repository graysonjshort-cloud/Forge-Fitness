# Forge Fitness v14.4 — Equipment Log

The old one-time equipment selector has been replaced by a persistent Equipment Log.

Features:
- Full Gym / Home Gym / Bodyweight quick setup
- Detailed equipment catalog
- Add/remove individual equipment
- Add custom equipment
- Equipment persists in SQLite
- Existing profile equipment automatically migrates
- Legacy `profile.equipment` stays synchronized so the current plan generator and substitution system remain compatible
- Existing users can edit the log from Plan > Overview > Manage Equipment Log
