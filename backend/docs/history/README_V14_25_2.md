# Forge Fitness v14.25.2 — Anvil Logo

The actual application header logo has been changed from the white `F` in the red rounded
square to a white anvil inside the same Forge red rounded square.

This is implemented directly in `index.html` as an inline SVG, so:
- it stays sharp at every screen size,
- it does not require an external image file,
- it loads instantly with the UI,
- and the red/white Forge branding remains unchanged.

The FORGE wordmark remains beside the new anvil.
