# Forge Fitness v14.25.3 — Actual UI Icon Overhaul

This build updates the real application UI.

The Equipment Log no longer uses unrelated emoji/generic symbols. It now renders embedded
SVG gym-equipment illustrations for free weights, bars, plates, kettlebells, benches,
racks, cable machines, strength machines, accessories, bodyweight gear, cardio equipment,
sandbags, vests, clubs/maces, and more.

The bottom navigation also replaces the old Unicode symbols with a consistent custom SVG
set for Home, Plan, Workout, Progress, Nutrition, and Coach.

No external icon library or internet connection is required for these icons.
