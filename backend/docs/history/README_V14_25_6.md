# Forge Fitness v14.25.6 — Welcome Hero Redesign

The actual welcome screen has been redesigned.

The old weightlifting emoji has been removed and replaced with an embedded SVG hero illustration:
- athlete pressing a barbell overhead,
- metallic barbell treatment,
- Forge red training shirt,
- subtle anvil mark,
- red glow and training-grid backdrop,
- integrated `TRAIN • TRACK • PROGRESS` caption.

The artwork is part of the app UI itself, not a concept image or external asset.
It scales cleanly on different screen densities and requires no image download.
