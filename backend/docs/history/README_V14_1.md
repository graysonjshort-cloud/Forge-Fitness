# Forge Fitness v14.1 — Functional Strength Trend

The Progress strength chart is no longer decorative.

It now reads real logged sets from SQLite and supports:
- Overall Strength Index
- Per-exercise estimated 1RM
- Exercise selector
- 30D, 90D, 1Y, and ALL filters
- Tap/click data points for date and set details
- Current, best, and percentage-change summaries

Overall Strength uses each exercise's first recorded estimated 1RM as a 100-point baseline, then averages normalized exercise performance by date. This avoids directly comparing unrelated lifts such as curls and squats in pounds.
