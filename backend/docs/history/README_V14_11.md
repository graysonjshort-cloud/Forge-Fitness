# Forge Fitness v14.11 — Core Frequency

Core training is no longer generated as a standalone workout.

Users can choose how many regular workouts per week include direct core work,
from 0 up to their selected training-days-per-week.

Forge spreads those core add-ons across the week. Each selected workout gets
up to two compatible core exercises, so core work coincides with an existing
Upper, Lower, Push, Pull, Legs, or Full Body workout.

The setting is available during onboarding and later in Training Settings.
Workout rows show `Core` when a session includes a direct core add-on.
