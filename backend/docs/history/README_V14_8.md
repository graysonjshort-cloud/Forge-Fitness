# Forge Fitness v14.8 — Preferences & Workout Splits

- Removed Training Time from the final Preferences screen (time remains set on Schedule).
- Cardio Preference is now selectable: None, Light, Moderate, High.
- Added Workout Split selection during onboarding.
- Added Forge Recommended, Full Body, Upper/Lower, Push/Pull/Legs, Body Part, and Hybrid structures.
- Workout Split and Cardio Preference persist in the user profile.
- Added Training Settings from Plan Overview so both can be changed later.
- Plan generation now honors the selected workout split.
